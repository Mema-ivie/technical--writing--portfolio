
# How to Create a Presentation in Canva on Mobile

## Overview

This guide explains how to create a presentation in Canva using a mobile device.

## Prerequisites

Before you start, make sure you have:

- Canva app
- Internet connection

## Steps

1. Open the **Canva** app.
2. Tap the search bar and type **"Presentation."**
3. Select a template or choose a blank presentation.
4. Add new slides by tapping **Add page**.
5. Tap the text box you want to edit, then tap **Edit** on the toolbar.
6. Tap **Share**, then tap **Download**.
7. Select **PDF** as the file type.
8. Choose your preferred pages and tap **Download**.

## Expected Result

Your presentation should contain the slides and content you added, and you should be able to download it as a PDF.

## Troubleshooting

If you experience problems while creating or downloading your presentation:

- Check your internet connection.
- Restart the Canva app and try again.
