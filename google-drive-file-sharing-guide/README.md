
# How to Share a File Using Google Drive on Android

## Overview

This guide explains how to share a file using the Google Drive app on an Android phone.

## Prerequisites

Before you begin, make sure you have:

- An internet connection
- The Google Drive app
- A file saved in Google Drive

## Steps

1. Open the **Google Drive** app.
2. Select the file you want to share.
3. Tap **More** next to the file.
4. Tap **Share**.
5. Enter the recipient's email address.
6. Select the permission you want to give the recipient.
7. Tap **Send**.

## Permission Options

Google Drive provides three main permission options:

- **Viewer** — Can view the file but cannot edit it.
- **Commenter** — Can view the file and add comments but cannot edit it.
- **Editor** — Can view, comment on, and edit the file.

## Expected Result

The recipient should receive access to the file according to the permission you selected.

## Troubleshooting

If you cannot share the file:

- Check your internet connection.
- Make sure you are signed in to the correct Google account.
- Close and reopen the Google Drive app, then try again.
