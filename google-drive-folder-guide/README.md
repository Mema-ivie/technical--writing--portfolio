
# How to Create a Google Drive Folder

## Overview

This guide explains how to create a folder in the Google Drive app on an Android phone.

## Prerequisites

- Android phone
- Google Drive app

## Steps

1. Open the Google Drive app.
2. Tap **Add (+)** in the bottom-right corner.
3. Tap **Folder**.
4. Enter a name for the folder.
5. Tap **Create**.

## Expected Result

The new folder should appear in your Google Drive.

## Troubleshooting

If the folder doesn't appear, check your internet connection and restart the app
